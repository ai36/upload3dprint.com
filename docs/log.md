Настроен процесс SDD с двумя ролями:
- главный агент: спецификации, plan.md, tasks.md, документация, этот журнал;
- субагент `fullstack` (`.claude/agents/fullstack.md`): код по утверждённым спецификациям.

Наблюдатель `.claude/scripts/spec-watch.sh` раз в 60 с сравнивает утверждённые спецификации со снимком последней реализации (`.claude/state/snapshot/`). Хук SessionStart (`.claude/settings.json`) при старте сессии поручает главному агенту запустить наблюдатель и передавать изменения fullstack.
