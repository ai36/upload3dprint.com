# upload3dprint.com

Сайт заказов 3D-печати: клиент загружает 3D-модель, выбирает материал и тираж, оплачивает и получает напечатанные детали почтой по США.

Проект ведётся по **spec-driven development**: сначала спецификация, потом план, задачи и код. Код не пишется, пока спецификация не утверждена человеком.

Связь с newlive: гипотеза H17 (D-2026-11-02-05). Сайт — заказ на печать без собственного принтера на старте и проект в портфолио Agama Labs.
